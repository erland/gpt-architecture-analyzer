# Architecture View Catalog

## 1. System context view
Show the analyzed system, users, and external systems. Keep to 5-9 nodes.

## 2. Container view
Show deployable/runtime units such as web app, API, worker, database, queue, cache, object storage.

## 3. Functional overview
Show user-visible capabilities grouped by major workflow or domain area.

## 4. Use case / user journey view
Show how an actor accomplishes important tasks using flowcharts or sequence diagrams.

## 5. Information overview
Show domain concepts, data ownership, lifecycles, and key relationships.

## 6. Runtime view
Show request/event flow through the system; use sequence diagrams for one scenario at a time.

## 7. Deployment view
Show processes, containers, hosts, cloud services, databases, volumes, networks, and ingress.

## 8. Integration view
Show APIs, events, scheduled jobs, file exchange, or external dependencies.

## 9. Complexity/coupling quadrant
Position modules/components by maintainability risk using scored tables and ASCII quadrant.

## 10. Hotspot/risk view
Show areas that deserve attention based on evidence, complexity, coupling, volatility, and architecture impact.
